# Stamp Rally design

The brief pins the passport-page and circular ink-stamp visual world. This takes precedence over unrelated concept challengers. Operate mode: a quiet personal travel desk, cream paper, forest-green binding, serif destinations and practical sans-serif controls. Code-first execution is a task-specific assumption, not a stored user workflow preference.

Main surface: compact brand masthead; large editorial title and inline collected/dream summary; sticky left composer; right passport-page grid with search and status filters. The first-use illustration is labeled as an example and is never stored as user history. Mobile stacks composer then collection with an explicit jump link.

Shared tokens own paper, binding, text, lines, five inks, spacing and typography. Real system serif stacks avoid remote dependencies and the source overhead of fonts. The stamps use double circular borders and a CSS mask to emulate ink wear. Card text stays fully opaque; only dream stamp art fades. Native form controls, fieldsets and dialog supply semantics. Reduced motion disables the sole card entrance.

No generic dashboard/sidebar chrome, gradients as decoration, external images or fabricated statistics. Strong small-screen usability and accessible errors outrank decorative detail. Risks to verify: long international names, color contrast, single-column overflow, dialog focus, persisted failure notices and multi-tab conflicts.
